# Face Detector

A lightweight face detection project built with Python and Go. It combines a computer vision application powered by OpenCV with a REST API developed in Go, providing a simple and modular approach to face detection.

## Project Structure

| Component | Description |
|---|---|
| [Python App](./python-app) | Face detection application built with Python and OpenCV. |
| [Go API](./go-api) | Backend API developed in Go. |

## Technology Stack

- **Python**
- **Go**
- **OpenCV**
- **NumPy**
- **Docker**

## Getting Started

### Prerequisites

- Git
- Python 3.6 or later
- Go
- Docker (optional, for containerized API deployment)

### Clone the Repository

```bash
git clone https://github.com/rodriaum/face-detector.git
cd face-detector
```
