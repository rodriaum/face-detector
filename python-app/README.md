# Python Face Detector

A lightweight face detection application built with Python, OpenCV, and NumPy. Designed to provide a straightforward way to detect faces through computer vision.

## Features

- **Face Detection:** Detect faces using OpenCV.
- **Image Processing:** Leverage OpenCV and NumPy for image processing.
- **Lightweight Setup:** Minimal dependencies and straightforward installation.

## Requirements

- Python 3.6 or later
- OpenCV
- NumPy

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/rodriaum/face-detector.git
cd face-detector/python-app
```

### 2. Install Dependencies

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Usage

Run the main application:

```bash
python main.py
```
